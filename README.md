# Seruen — честный пешеходный компаньон по Астане

*Seruen* (каз. «серуен») — прогулка. ИИ-помощник подсказывает, куда сходить в ближайшие 30–120 минут рядом с вами. Он учитывает время, погоду, закат, праздники РК, часы работы, детей, коляску и дорогу до аэропорта.

Кейс НИЦ Smart City · GDG Astana «Build with AI» 2026.

## Что умеет

- **1–3 места или мини-маршрут.** У каждого места есть «почему», «что делать», время пешком, время визита и часы работы со степенью уверенности: «проверено 10.2026», «данные OSM 2023 могли устареть», «часы неизвестны — не обещаем, что открыто».
- **Своя база + живой 2GIS.** Открытый датасет — основа; в момент запроса сервис `places-live` добавляет из 2GIS свежие часы работы, рейтинг, отзывы и доступность. Данные 2GIS не сохраняются, подпись «Работает на API 2ГИС» на карте.
- **Код считает, ИИ объясняет.**
  - Расстояния, часы работы, погоду и порядок маршрута считает код.
  - ИИ пишет текст только про места, которые выбрал код.
  - Выдуманных мест 0: в JSON-схеме ответа модели ID задан перечнем (enum), а guard проверяет каждый ответ.
- **Контекст Астаны.**
  - Время UTC+5, закат, праздники РК (25–26.10).
  - Режимы «гулять / коротко между тёплыми местами / только помещения» по ощущаемой температуре и ветру.
  - Маршрут с «тёплыми остановками» в холод.
- **Сценарии кейса:** прогулка у Mega Silk Way, кофе с розеткой, с ребёнком, турист перед вылетом (с учётом такси до NQZ), ночь, группа, коляска, афиша событий, старые названия («Нур Алем» → Alem.ai, «Думан» → Ailand).
- **Три языка:** русский, казахский, английский.
- **Приватность:**
  - точная точка остаётся в браузере, на сервер уходит клетка ~150 м;
  - история не хранится;
  - есть «Режим без ИИ» и кнопка «Удалить мои данные».
- **Панель «Как я выбирал»:** все шаги, веса, что ушло в ИИ и что не уходило.

## Данные

Данные собираются автоматически: CronJob по каждому источнику, затем Kafka-конвейер.

| Что | Сколько |
|---|---|
| Мест после склейки дублей | 2 702 |
| Из них подтверждены двумя источниками и больше | 315 |
| Событий из афиши sxodim | 97 |

Источники: OpenStreetMap, Overture Maps, Wikidata, Wikivoyage, visitastana.kz, sxodim.com. У каждого поля записаны источник, дата и уверенность. Данные © OpenStreetMap contributors (ODbL), Wikidata (CC0), Wikivoyage/Wikipedia (CC BY-SA), Overture Maps (CDLA), visitastana.kz и sxodim.com — со ссылкой на источник.

## Архитектура

15 онлайн-микросервисов (включая живой слой 2GIS) и 9 фоновых воркеров работают в одном кластере DigitalOcean Kubernetes:

| Слой | Что |
|---|---|
| Шина | Kafka (Strimzi) |
| Хранилища | PostgreSQL + PostGIS (CloudNativePG), OpenSearch (BM25 + k-NN + гео), Redis, ClickHouse, MinIO |
| Маршруты | свой OSRM по карте Астаны |
| Платформа | Linkerd (mTLS), KEDA, HPA, Argo CD, Prometheus/Grafana, Loki, Tempo (OpenTelemetry), cert-manager |

Подробно — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Модель: OpenAI `gpt-6-luna` (≈ $0,0007 за ответ). Эмбеддинги: `text-embedding-3-large` (1024).

## Как запустить

```bash
# 1. окружение
uv venv --python 3.12 .venv && . .venv/bin/activate && uv pip install -r requirements.txt
cp .env.example .env            # впишите OPENAI_API_KEY

# 2. данные (≈ 3–4 мин, кэшируется)
make ingest

# 3. вся система одним процессом (тот же код, что в кластере) → http://localhost:8000
make dev

# 4. тесты и сценарии
make test && make eval           # → docs/TEST_SCENARIOS.md

# 5. кластер: платформа, затем приложение
bash deploy/scripts/bootstrap.sh
make build && kubectl apply -k deploy/apps
```

## Структура

```
seruen/common     контракты (models.py), конфиг, геометрия, вызовы между сервисами
seruen/engine     логика: часы работы, погода/время, разбор запроса, оценка, маршрут, шаблоны
seruen/services   14 онлайн-сервисов (FastAPI)
seruen/workers    9 воркеров Kafka/Celery + задачи сбора и начальной загрузки
seruen/ingest     сборщики шести источников, нормализация, склейка дублей, качество, эмбеддинги
web/              интерфейс (MapLibre + OpenFreeMap), ru/kk/en
deploy/           Helm-values платформы, манифесты приложения, скрипты
tools/            прогон тест-сценариев
docs/             архитектура, этика, сценарии, контракты
```
