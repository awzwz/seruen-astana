# Дизайн

Как искали интерфейс: от вариантов в стиле Armeta (A–C) к простым (D, E), своему «Небу Астаны» (F) и итоговому **G — «2GIS × iOS»**, который стал рабочим интерфейсом в [`web/`](../web).

- [`PROMPT.md`](PROMPT.md) — исходный бриф.
- [`src/g-template.html`](src/g-template.html), [`src/f-template.html`](src/f-template.html) — шаблоны макетов F и G.

Готовые макеты собирались из записанных ответов системы, в которых есть живые данные 2GIS. Правила 2GIS (п. 4.2) запрещают хранить и публиковать эти данные, поэтому сами макеты и записи в репозиторий не входят — смотрите итог на [живом сайте](https://seruen.129-212-254-180.sslip.io).
